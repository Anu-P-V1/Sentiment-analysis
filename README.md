# 💬 Sentiment Analysis using CNN + LSTM

## 📌 Overview
This project combines **CNN and LSTM** to classify text sentiment as positive or negative. It captures both **local features (via CNN)** and **contextual meaning (via LSTM)** for better prediction accuracy.

## 🧰 Tech Stack
- Python, TensorFlow, Keras
- NLP preprocessing, Tokenization, Padding

## ⚙️ Features
✅ Text preprocessing pipeline  
✅ CNN + LSTM hybrid model  
✅ Predicts real-time sentiment  

## 🚀 How to Run
```bash
pip install -r requirements.txt
python main.py
```
